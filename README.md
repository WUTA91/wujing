# WUJING・無境 团队官网

综合创作团队官网・灰白黑银灰极简风格・响应式多端适配

## 一、项目文件说明



| 文件           | 作用                                                                            |
| ------------ | ----------------------------------------------------------------------------- |
| `index.html` | 页面结构。顶部导航、首页、团队介绍、联系方式、页脚的**文字内容**都在这里改                                       |
| `style.css`  | 全部样式。配色、深浅色主题、间距、动画效果都在这里。改颜色只动文件顶部的 `:root` 和 `html[data-theme="dark"]` 变量即可 |
| `script.js`  | 页面逻辑 + **数据配置区**。成员、项目、公告的增删改都改文件顶部，不需要动下方代码                                  |
| `README.md`  | 本文档                                                                           |
| `assets/bgm.mp3` | 背景音乐文件，想换曲子直接覆盖这个文件即可                                                      |

三个代码文件放在**同一文件夹**下，双击 `index.html` 即可在浏览器中打开。

## 二、部署上线

### 方式一：本地直接使用（最简单）

双击 `index.html`，用浏览器打开即可，无需任何环境。

### 方式二：免费托管上线（推荐）



1. **GitHub Pages / Vercel / Netlify / Cloudflare Pages** 任选一个；

2. 把 `wujing-site` 文件夹里的三个文件（含以后新增的图片）整个上传；

3. 平台会自动生成一个公网链接，别人就能访问了。

### 方式三：自有服务器

把三个文件上传到服务器 Web 目录（如 Nginx 的 `html` 目录）即可。

> 提示：如果上传后图片不显示，请确认图片与三个文件在同一目录，且 
>
> `image`
>
>  字段填的是图片文件名或完整网址。

## 三、常见修改教程

### 1. 修改团队名称 / 标语

打开 `index.html`，搜索下面注释：



* `① 首页 Hero`：主视觉为商标图（换图替换 `assets/logo.jpeg`），标语 `<p>` 和服务条目可直接改；**背景壁纸**为 `assets/hero-bg.png`，直接替换该文件即可换壁纸（上下会自动渐变过渡回页面原色，深色模式自动压暗）

- **左上角商标**：把新商标图放进 `assets/` 文件夹并命名为 `logo.jpeg`（或改 `index.html` 中 `<img src="assets/logo.jpeg">` 的文件名）。浅色模式自动融合白底，深色模式自动反相为白字，无需额外处理

* 浏览器标签页标题：改 `<title>`

### 2. 修改团队介绍

打开 `index.html`，搜索 `② 团队介绍`，直接改 `<p>` 里的文字。

### 3. 新增成员（★ 重点）

打开 `script.js` 顶部 `MEMBERS` 数组，**复制一条 {} 加上英文逗号粘贴**，改成：

```
{ name: "新成员名字", role: "负责方向", bio: "一句话介绍", detail: "详细简介（选填，弹窗里展示）", bg: "assets/bg.jpg", avatar: "" },
```

保存刷新即可。`avatar` 留空 `""` 时，头像自动用姓名第一个字生成圆形占位。

**成员卡片点击后弹出详情弹窗**：弹窗展示头像、姓名、职务、`bio` 和 `detail`。`detail` 是详细简介，留空 `""` 时弹窗里会显示"详细简介整理中，敬请期待…"占位，等你之后补文案（支持换行，直接写多行文字即可）。

#### 成员弹窗背景图怎么添加
弹窗顶部会铺一张背景图，图片会自动**压暗处理**（再花再亮的图都能压得住）；头像、姓名、职务以亮色显示在图上，个人简介显示在下方干净区域，永远清晰：

1. **把图片放进 `assets/` 文件夹**，如命名为 `member-bg.jpg`
2. **在 `bg` 字段填文件名**：`bg: "assets/member-bg.jpg"`
3. 保存刷新，点开该成员弹窗即可看到

要点：
- **建议横图**（3:2 或 16:9 左右），会自动居中铺满裁剪；图会自动压暗，**不需要特意选暗图**
- 弹窗结构：顶部背景图区（头像 + 姓名 + 职务）+ 下方纯色简介区（`bio` + `detail`），深浅色主题都兼容
- 不填 `bg`（留空 `""`）就是原来的纯色弹窗，不影响其他成员

#### 成员头像怎么添加（3 步）
1. **把头像图片放进 `assets/` 文件夹**，如命名为 `member1.jpg`
2. **在 `avatar` 字段填文件名**：`avatar: "assets/member1.jpg"`
3. 保存刷新即可看到圆形头像（自动居中裁剪）

要点：
- **建议正方形或竖版照片**（1:1 ~ 3:4），横版长图会被裁掉两侧
- 必须写相对路径 `assets/xxx.jpg`，不要填电脑绝对路径
- 不想放头像就留空 `""`，显示姓名首字占位

### 4. 新增作品（★ 重点）

打开 `script.js` 顶部 `PROJECTS` 数组，复制一条 {} 加逗号粘贴，改成：

```
{
  title: "项目名称",
  category: "视频宣发",          // 或“网页制作”
  desc: "项目一句话描述",
  image: "assets/cover.jpg",     // 封面图，可留空 ""
  images: ["assets/pic1.jpg", "assets/pic2.jpg"],  // 弹窗多图（选填，可多张）
  detail: "项目详细介绍（选填，弹窗里展示）",
  link: "https://你的项目链接.com"  // 弹窗内「立即体验」按钮跳转地址
},
```

#### 弹窗多图怎么添加
项目弹窗里可以放**多张图左右滑动浏览**（带圆点指示 + 左右箭头，手机上手指直接滑）：

1. **把图片都放进 `assets/` 文件夹**
2. **在 `images` 字段填图片数组**：`images: ["assets/pic1.jpg", "assets/pic2.jpg", "assets/pic3.jpg"]`
3. 保存刷新，点开该项目弹窗即可左右滑动看图

要点：
- **填了 `images` 就优先用它**（弹窗里滑动浏览）；不填 `images` 就用上面的单张 `image`；两个都不填显示灰色占位
- 图片建议统一比例（如都 16:9 或都 3:2），滑动切换才整齐
- 封面卡（列表页那张）仍然看 `image` 字段，所以想换列表封面改 `image` 就行，`images` 只影响弹窗

#### 封面图怎么添加（3 步）
1. **把图片文件放进 `assets/` 文件夹**（与 logo、壁纸同一个目录），例如把图片命名为 `project1.jpg`
2. **在 `image` 字段里填图片文件名**：`image: "assets/project1.jpg"`（注意开头是 `assets/`）
3. 保存刷新即可看到封面

要点：
- **图片比例建议 16:9 或 3:2 的横图**。卡片封面是一块横向区域，竖图或方图会被自动裁剪居中显示（不会变形，但两侧/上下可能裁掉一部分）
- **必须用相对路径**：`assets/xxx.jpg` 这种写法，不要把电脑上的绝对路径（如 `D:\图片\xx.jpg`）填进去，否则换电脑或上线后会找不到图
- `image` 留空 `""` 时显示灰色占位块（上面是分类名），不影响使用
- 部署时记得把图片和三个文件放在**同一套文件**里一起上传

说明：

* 卡片区**横向滑动**：鼠标拖拽，或用右上角左右按钮；手机端手指左右滑

* **点击卡片弹出项目详情弹窗**（图片、标签、标题、描述、详细介绍），弹窗图片支持**多张滑动浏览**（圆点指示 + 左右箭头 + 拖拽/手指滑动），弹窗底部有**「立即体验」按钮**，点击后在新标签页跳转到 `link` 地址；`detail` 留空 `""` 时显示"项目介绍整理中，敬请期待…"占位，可后补

* 鼠标中键 / Ctrl+点击卡片仍可直接在新标签页打开项目链接（浏览器默认行为）

* 想删除某张卡片，删掉对应 {} 即可

* 卡片数量多会自动出现 "还有更多" 渐隐提示

### 5. 增删公告

编辑 `script.js` 顶部 `ANNOUNCEMENTS` 数组：新增公告复制一条 {} 加逗号粘贴修改内容，删除直接删掉对应条目，保存刷新即生效。（官网不开放访客发布 / 删除公告）

### 5.5 增删成长历程节点（时间线）

打开 `script.js` 顶部 `TIMELINE` 数组，复制一条 {} 加逗号粘贴，改成：

```js
{ date: "2026.10", title: "节点标题", text: "这段历程的描述（选填，留空 \"\" 则不显示）" },
```

时间从早到晚排列，页面自动从上到下展示。`date` 随便写格式（如 "2025.12"、"2026.09.17"、"未来"），会以灰色小字显示在标题上方。

### 6. 修改联系方式

打开 `index.html`，搜索 `⑥ 联系方式`：



* 邮箱：改 `mailto:contact@wujing.example` 和显示的文字

* 抖音：**整卡可点击跳转抖音主页**，换账号改抖音卡片 `href` 里的链接，显示文字也顺手改

* 微信：直接改显示文字即可

* "发送邮件联系我们" 按钮：同样改 `mailto:` 地址

### 7. 调整整体配色

打开 `style.css` 顶部：



* `:root` 是**浅色模式**配色

* `html[data-theme="dark"]` 是**深色模式**配色

改注释里标明的变量（如 `--text` 主文字色、`--bg` 背景色、`--border` 边框色）即可全局生效。

### 8. 深浅色切换

页面右上角月亮 / 太阳图标一键切换，选择会被浏览器记住（下次打开保持）。

### 9. 背景音乐

- **想换曲子**：把新的 mp3 放进 `assets/` 并命名为 `bgm.mp3`，直接覆盖旧文件即可，不用改代码
- **播放规则**：浏览器不允许一打开就自动出声，所以访客**第一次点击 / 滚动页面**后自动开始播放；右下角小圆钮随时暂停 / 继续，上次的开关状态浏览器会记住
- **不想有背景音乐**：删掉 `index.html` 末尾的 `<button class="music-toggle" ...>` 和 `<audio id="bgm" ...>` 两段，再删 `style.css` 里 `12.5 背景音乐悬浮按钮` 那一节、`script.js` 末尾「背景音乐」那段即可

## 四、功能清单



* 深色 / 浅色模式一键切换，自动记忆

* 顶部导航：首页 / 团队介绍 / 成长历程 / 成员 / 项目作品 / 公告 / 联系方式，平滑滚动定位

* 成长历程时间线：垂直时间轴展示团队里程碑，节点由 `TIMELINE` 数组管理

* 移动端导航自动折叠为汉堡菜单

* 项目卡片横向滑动浏览，鼠标拖拽 + 按钮 + 触屏滑动；点击卡片弹出详情弹窗，弹窗内「立即体验」一键跳转项目

* 成员卡片点击弹出详情弹窗（头像 / 姓名 / 职务 / 简介），详细介绍可后补

* 公告由代码数组统一管理，增删改编辑 `script.js` 顶部即可

* 成员卡片自动生成文字头像，新增成员改一行即可

* 右下角背景音乐按钮，访客首次交互后自动播放，可随时暂停，状态自动记忆

* 多向入场动画：首屏主视觉/标语/服务条错峰滑入，滚动到各板块时内容从不同方向滑入渐显，克制不花哨

* 响应式适配电脑 / 平板 / 手机，滚动渐显动画克制简约，支持系统 "减少动态效果" 设置

* 社交分享卡片（Open Graph）：把链接发到微信 / QQ / 微博时自动显示标题 + 简介 + logo 预览图。想换预览图就替换 `assets/logo.jpeg`，或改 `index.html` `<head>` 里 `og:image` 指向的文件（注意要用线上完整网址，不能写相对路径）
